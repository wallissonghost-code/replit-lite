# VUCLIP

Primeira versão do app/site estilo TikTok para personagens de IMVU.

## Stack
- HTML
- CSS
- JavaScript

## MVP
- Feed vertical
- Publicação de fotos e vídeos
- Curtidas
- Comentários mockados
- Perfil básico

## Como usar
Abra o arquivo index.html no Replit ou em qualquer hospedagem estática.
